## 🚀 Features

### 💳 CC Generator
- Generate Luhn-valid credit card numbers
- Custom BIN prefix (6-8 digits)
- Quantity up to 5000 cards
- Network: Visa, Mastercard, Amex
- Random expiry, CVV, cardholder name
- Download as CSV/JSON
- 3D holographic card preview

### ✅ CC Live Checker
- Real Stripe tokenize check (Live/Die)
- Real-time monitor (Live/Die/Unknown counter)
- Auto-fill from generated cards
- Cancel & restart anytime

### 🔍 BIN Lookup
- Fetch bank info via binlist.net API
- 102+ popular BINs database
- 49 countries filter
- Click BIN → auto-generate

### 🏠 Address Generator
- 48 countries/locales (fakerapi.it)
- Quantity 1-50 per generate
- Phone number with correct country prefix
- Name, address, city, ZIP, phone, email
- Copy per card + Copy All

### 🛠️ Advanced Tools
- **Mass Generate** — Up to 5000 cards, progress bar, download TXT
- **BIN Extractor** — Extract unique BINs from card list
- **Card Formatter** — Convert between pipe/csv/json/plain
